# Code of Conduct

This repository exists to improve engineering quality and reuse. Work here should stay factual, respectful, and reviewable.

## Expected behavior

- argue from evidence
- keep disagreement technical
- document decisions instead of relying on chat memory
- treat review, verification, and rollback as first-class work

## Unacceptable behavior

- personal attacks
- hostile or abusive language
- hiding important workflow changes only in private chat
- intentionally bypassing the agreed engineering process without documenting the reason

## Enforcement

Repository maintainers may edit, close, or remove contributions that violate these rules.
